# Tax Marketplace Dashboard

Учебный демонстрационный кейс по сравнению налоговых режимов для бизнеса на маркетплейсах.

## Что показывает

- сравнение УСН «Доходы минус расходы» и ОСНО;
- расчет налоговой базы;
- расчет НДС;
- расчет налога на прибыль;
- расчет чистой прибыли по каждому сценарию;
- интерактивное изменение структуры расходов;
- мгновенный пересчет финансового результата;
- оценку разницы в прибыли за месяц и год;
- визуализацию структуры расходов и налоговой нагрузки.

## Особенность кейса

Дашборд показывает сценарное финансово-налоговое моделирование: пользователь меняет доли расходов и сразу видит, как это влияет на налоги и чистую прибыль.

Это учебный кейс на демонстрационных данных.

## GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите в корень репозитория `index.html` и `README.md`.
3. Откройте `Settings -> Pages`.
4. Выберите `Deploy from a branch`.
5. Укажите ветку `main` и папку `/(root)`.
6. Сохраните настройки.

Рекомендуемое имя репозитория:

`tax-marketplace-dashboard`
